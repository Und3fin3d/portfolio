Short-term memory in a memristor

The same voltage pulse produces more current when conductance remains from an earlier pulse.

Press Play to apply the first pulse.

Input → device → output

Voltage, conductance and current

Sequence

Step 1First pulse

Applied voltage increases conductance. Current flows through the memristor.

Step 2Between pulses

Voltage and current return to zero. Conductance decays gradually.

Step 3Next pulse

The same voltage produces more current if conductance remains elevated.

Step 4Relaxation

Conductance returns towards its initial value after stimulation stops.
